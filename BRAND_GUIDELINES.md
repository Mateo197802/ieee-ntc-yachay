# IEEE Nanotechnology Council Yachay Tech - Visual Brand Guidelines

Official visual identity standards for IEEE Nanotechnology Council Yachay Tech Student Branch Chapter.

---

## 🎨 Color Palette

| Tone | Hex Code | Purpose |
|------|----------|---------|
| **Navy** | `#1F3E65` | Header background, footer, primary headers |
| **Deep Blue** | `#264061` | Secondary backgrounds, hero gradients |
| **Institutional Blue** | `#04608E` | Cards, icons, section borders |
| **Cyan** | `#0587BD` | Active link highlights, primary buttons, accents |
| **Slate** | `#465D64` | Subtitles, secondary text, metadata labels |
| **White** | `#FFFFFF` | Backgrounds, primary text on dark containers |

---

## 🔤 Typography

- **Headings**: `Anton` (Display font for main impact titles)
- **Subtitles & Body**: `Inter` / `Open Sans` (Clean sans-serif typography)

---

## 🛡️ Logo Usage & Clear Space

- Always maintain the official badge shape (`NTC` hexagon inside rounded capsule badge).
- Do not stretch, distort, recolor, or modify official IEEE logos.
- Ensure minimum contrast ratios (4.5:1 for body text, 3:1 for large display titles) adhering to WCAG 2.1 AA.
